# Part 12 — Observability

## What You'll Learn

How to know what your API is actually doing in production: logging, structured logging, metrics, tracing, distributed tracing, correlation/request IDs, OpenTelemetry concepts, error monitoring, and SLI/SLO/SLA. Includes a full walkthrough of one request traced across multiple services.

## Prerequisites

[Part 11 — Microservices & Distributed Systems](../11-microservices-distributed-systems/README.md) is helpful for the distributed tracing chapters, but not required for logging/metrics.
