# Part 2 — REST API Design

## What You'll Learn

How to design clean, predictable, evolvable HTTP APIs using REST principles: resources, CRUD operations, path/query parameters, pagination, filtering, sorting, naming conventions, versioning, and contracts. This is the "API design" skill that separates a working endpoint from a *good* one.
