# Part 11 — Microservices & Distributed Systems

## What You'll Learn

When (and when not) to split a system into services: monolith vs. microservices trade-offs, API gateways, service discovery, load balancing, service-to-service authentication, REST vs. gRPC, Protocol Buffers, distributed transactions, the Saga pattern, and event-driven microservices. This part explains trade-offs honestly rather than assuming microservices are always the "more advanced" choice.

Parts 3–9.
