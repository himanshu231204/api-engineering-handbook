# Part 9 — Real-Time APIs & Webhooks

## What You'll Learn

How to move data between client and server without waiting for a poll: polling, long polling, webhooks (both sending and receiving them correctly), WebSocket, Server-Sent Events, streaming APIs, and the hard operational realities — event ordering, duplicate events, and webhook signature verification.
