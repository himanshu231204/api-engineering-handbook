# What Is an API? — long video (Part 0, topic 1)

Source project for the roadmap video. The finished MP4 is not committed (see `video/ROADMAP.md`).

- `research.md`, `script.md`, `script.json`, `captions.srt`, `seo.md`, `thumbnail.png` — the written package.
- `hf/` — the HyperFrames project (HTML scenes generated by `build/build.py` from `build/timing.json`).
- `build/` — script, voice (Kokoro), alignment (faster-whisper), SFX mix and build scripts.
- `demo/main.py` — the handbook's FastAPI example; `demo/real_output_8000.txt` is its real `curl -i` output shown on screen.
- `hf/assets/CREDITS.md` — every asset and its license.

Rebuild: `python3 build/build.py` after changing `build/script_lines.py` and re-running the voice and align steps, then `cd hf && npx hyperframes render --quality delivery`.
