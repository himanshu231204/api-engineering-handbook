# API Architecture at a Glance — long video (Part 0, topic 2)

Source project for the roadmap video. The finished MP4 is not committed (see `video/ROADMAP.md`).

- `research.md`, `script.md`, `script.json`, `captions.srt`, `seo.md`, `thumbnail.png` — the written package.
- `harvest/` — output of `video/tools/harvest_chapter.py` for the chapter.
- `hf/` — the HyperFrames project (HTML scenes generated by `build/build.py` from `build/timing.json`).
- `build/` — script, voice (Kokoro), alignment (faster-whisper), SFX mix and build scripts. `_head.py` / `_beats.py` / `_foot.py` are the three parts `build.py` is assembled from.
- `demo/` — `run_demo.sh` and `real_output.txt`: the real run of `examples/llm-gateway` shown on screen.
- `thumb/` — thumbnail source (`index.html`, `shot.js`).
- `hf/assets/CREDITS.md` — every asset and its license.

Rebuild: edit `build/script_lines.py` or `build/_beats.py`, then in `build/`: `python make_voice.py` → `ffmpeg -i voice.wav -ar 16000 -ac 1 voice16.wav` → `python align.py` → `cat _head.py _beats.py _foot.py > build.py && python build.py` → `python mix.py` → `python post.py`, then `cd hf && npx hyperframes render --quality delivery`. The Kokoro model files go in `models/` (git-ignored).
